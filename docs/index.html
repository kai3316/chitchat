Why ChitChat?

Built for speed, privacy, and independence.

⚡

P2P LAN Direct

Messages flow directly over your local network with sub-millisecond latency and zero server cost. mDNS auto-discovers peers — no IP typing needed.

🔐

End-to-End Encrypted

TLS 1.3 for transport, AES-256-GCM for application-layer encryption. Ed25519 certificates with TOFU pairing ensure you're talking to the right person.

🌍

6 Platforms

iOS, Android, Windows, macOS, Linux, and Web — all from a single Flutter codebase with Material Design 3. Dark mode by default, beautifully native.

📁

Rich Messaging

Text, images, files, voice messages, link previews. Typing indicators, read receipts, emoji reactions. Everything you expect from a modern messenger.

🏠

Self-Hosted Relay

A single ~8 MB Go binary is all you need. Run it on a Raspberry Pi, VPS, or home server. No vendor lock-in, no monthly fees, no data mining.

🛡️

No Phone Number

Pair devices with 8-digit codes or QR. No phone number, no email, no account. Your identity is an Ed25519 keypair, not a marketing database entry.

Get Started

Three components. Five minutes.

# 1. Start the Python daemon (P2P networking + local API)
cd core && pip install websockets && python daemon.py

# 2. Run the Flutter app (connects to daemon on localhost:9876)
cd app && flutter run

# 3. (Optional) Deploy the relay server for WAN messaging
cd server && go run main.go
# Deploy to VPS: GOOS=linux go build -o relay && scp relay user@vps:/opt/chitchat/

Requires Python 3.10+, Flutter 3.0+, and optionally Go 1.21+.
See README for detailed setup instructions.
