Features

Everything you need.
Nothing you don't.

ChitChat combines the best of P2P and cloud chat into one polished experience.

P2P LAN Chat

Direct device-to-device messaging over your local network. Zero server costs, sub-millisecond latency, and mDNS automatic peer discovery -- no typing IP addresses.

End-to-End Encrypted

TLS 1.3 secures every connection. AES-256-GCM encrypts all data. Ed25519 certificate-based identity with TOFU pairing ensures trust on every connection.

6-Platform Support

Native apps for iOS, Android, Windows, macOS, Linux, and Web from a single Flutter codebase. Material Design 3 with full dark mode across all targets.

Rich Media Sharing

Share text, images, files, and voice messages. Typing indicators, read receipts, and emoji reactions bring conversations to life in a modern messenger.

Self-Hosted Relay

A compact ~8 MB Go binary with zero runtime dependencies. Deploy on a VPS, behind nginx, or on a Raspberry Pi. No vendor lock-in, no monthly fees.

Modern UI

Material Design 3 with an indigo/violet accent palette. Full dark mode, fluid animations, and platform-adaptive controls that feel native everywhere.

Get Started

Three commands
to running locally.

You'll need Python 3.10+, Flutter 3.0+, and optionally Go 1.21+.

1. Start the Python daemon Python 
# Install the daemon and start it
$ cd core && python daemon.py

# Opens WebSocket on ws://127.0.0.1:9876 for Flutter
# Starts mDNS discovery on _chitchat._tcp
# Listens for P2P connections on TCP :9877
2. Run the Flutter app Flutter 
$ cd app
$ flutter pub get
$ flutter run

# Connects to daemon on localhost:9876
# Launches on your connected device or desktop
3. (Optional) Run the relay server Go 
$ cd server
$ go run main.go

# Or build a static binary (~8 MB):
$ go build -ldflags="-s -w" -o chitchat-relay main.go

# Listens on :9878 -- WebSocket relay hub
