Features

Everything you need.
Nothing you don't.

ChitChat combines the best of P2P and cloud chat into one polished experience.

P2P LAN Chat

Direct device-to-device messaging over your local network. Zero server costs, sub-millisecond latency, and mDNS automatic peer discovery -- no typing IP addresses.

End-to-End Encrypted

TLS 1.3 secures every connection. AES-256-GCM encrypts all data. Ed25519 certificate-based identity with TOFU pairing ensures trust on every connection.

Works on Every Device

The daemon runs on Windows, macOS and Linux; the UI is a web page, so phones and tablets on the same network join with nothing to install. Optional Flutter client for Windows and Web.

Rich Media Sharing

Share text, images, files, and voice messages. Typing indicators, read receipts, and emoji reactions bring conversations to life in a modern messenger.

Self-Hosted Relay

A compact ~8 MB Go binary with zero runtime dependencies. Deploy on a VPS, behind nginx, or on a Raspberry Pi. No vendor lock-in, no monthly fees.

Modern UI

Material Design 3 with an indigo/violet accent palette. Full dark mode, fluid animations, and platform-adaptive controls that feel native everywhere.

Get Started

Two commands.
Then just chat.

You need Python 3.10+. The first run installs the rest and opens the UI in your browser. Go 1.21+ is only needed for the optional relay.

1. Start the daemon Shell 
# Windows
> run.bat

# macOS / Linux
$ ./run.sh

# First run creates .venv and installs dependencies.
# mDNS discovery on _chitchat._tcp, P2P on TCP :9877,
# Web UI on HTTP :9875, WebSocket on :9876.
2. Open the chat Browser 
# The browser opens by itself; or go to:
http://localhost:9875

# On a phone or tablet, same Wi-Fi:
#   http://<this-pc-ip>:9875
# Peers appear in the list automatically.
Optional: relay for cross-network Go 
$ cd server
$ go run main.go

# Or build a static binary (~8 MB):
$ go build -ldflags="-s -w" -o relay-server main.go

# Listens on :8080 -- WebSocket relay hub
# Point clients at it with: --relay ws://HOST:8080
